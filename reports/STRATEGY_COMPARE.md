# Сравнение стратегий (replay, не live)

Рабочий PaperRuntime **не менялся**: шаг 0,50%, 1000 USDT, BTC/ETH/SOL/XRP.

Сравнение гонялось на изолированных движках (`sqlite://`) и на синтетической серии с регулярным откатом ~0,7%. Это проверка, что проводка BUY→SELL жива, **не** доказательство прибыли на рынке.

Наблюдения на этой серии:

- шаг 0,30% — циклов 0 (цель `net_target` после комиссий/slippage не выполняется, как в example-конфиге);
- шаг 0,50% — 1 цикл, realized ≈ +0,80 на 1000;
- шаг 1,00% — циклов 0 (откат 0,7% не достаёт лимит);
- адаптивный шаг от ATR (~0,67%) совпал с 0,50% на этой серии.

Период train (70%) и test (30%) дали тот же качественный вывод. На реальных свечах Binance отчёт нужно пересчитать после окончания `market-sync`:

```bash
python -m app.cli replay --config configs/paper.binance_public.usdt.yaml \
  --candles var/market/candles.db --symbol BTC/USDT --interval 1h \
  --out reports/BACKTEST_REPORT.md
```

Пересчёт на реальных BTC/USDT 1h (Binance Vision, ~9000 баров, train/test 70/30), консервативная модель свечи:

| period | step | cycles | realized | заметка |
| --- | --- | --- | --- | --- |
| train | 0.30 | 0 | 0 | ниже net_target после комиссий |
| train | 0.50 | 1 | +0.76 | как live-шаг |
| train | 1.00 | 1 | +0.76 | |
| test | 0.30 | 0 | 0 | |
| test | 0.50 | 1 | +0.33 | |
| test | 1.00 | 1 | +0.54 | |
| оба | adaptive 0.30 | 0 | 0 | ATR часа ~0.15% → шаг упёрся в 0.30 |

Режим эвристики на всей выборке: RANGE (не прогноз). ~50% часовых баров имеют размах ≥0.5%, но консервативный replay не считает это гарантированным fill.

Вывод: не крутить live-шаг ради числа сделок. Полный файл: `reports/BACKTEST_BINANCE_1H.md`.
